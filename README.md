# موقع شركة وائل البكري للتدفئة المركزية

نموذج أولي لموقع شركة تدفئة مركزية في حلب وإدلب: مضخات حرارية، تدفئة أرضية، وراديترات.

## البنية

| المجلد | المحتوى |
|---|---|
| `site/` | الموقع نفسه (HTML وCSS وJS وصور مضغوطة)، جاهز للرفع على أي استضافة ملفات ثابتة |
| `site/css/style.css` | كل الأنماط |
| `site/js/` | ملف لكل قسم: `hero.js` (الغلاف الحراري)، `journey.js` (رحلة الحرارة)، `floor.js` (كشف الأرضية)، `gallery.js` (المعارض الأفقية)، و`scroll-utils.js` (أدوات مشتركة) |
| `site/assets/images/` | `scenes` (مشاهد التمرير)، `products` (المنتجات)، `gallery` (المعارض) |
| `docs/` | ملفات التخطيط ومعلومات الشركة وأفكار الصور |
| `source-images/` | الصور الأصلية غير المضغوطة (لا تُنشر مع الموقع) |

## التشغيل محلياً

```bash
node dev-server.js
```

ثم افتح `http://localhost:4173`.

## النشر

كل المسارات في الموقع نسبية، فيعمل من أي استضافة ومن أي مجلد دون تعديل.

### على GitHub Pages (مؤقتاً)

الرابط: `https://ammarabokh.github.io/WaelBakri/`

يعمل بأي من إعدادَي Pages:

- **Deploy from a branch** (الإعداد الحالي): يُنشر المستودع كله، و`index.html` في الجذر يحوّل الزائر إلى `site/`. الرابط النهائي يصبح `.../WaelBakri/site/`.
- **GitHub Actions** (الأنظف): من **Settings ← Pages ← Source** اختر **GitHub Actions**. عندها ينشر `.github/workflows/pages.yml` محتوى `site/` مباشرة عند كل رفع إلى `main`، ويعمل الموقع على `.../WaelBakri/` بلا تحويل.

### على استضافة عادية

الأفضل: ارفع **محتوى** مجلد `site/` (وليس المجلد نفسه) إلى المجلد العام في الاستضافة، مثل `public_html`، بحيث يكون `index.html` في الجذر. لا يحتاج الموقع PHP ولا قاعدة بيانات.

إن رفعتَ المستودع كاملاً، فصفحة التحويل في الجذر تفتح `site/` تلقائياً، لكن مجلدي `docs/` و`source-images/` سيكونان متاحين للزوار أيضاً.

## تنويه عن الصور

- الصور الموسومة «صورة توضيحية» مولّدة بالذكاء الاصطناعي، وليست مشاريع منفذة للشركة.
- صور المضخات الحرارية مأخوذة من موقع شركة رتم للطاقة (ritimen.com) وتحتاج إذنهم قبل النشر العلني.
- مسار الأنابيب وطبقات الأرضية في المشاهد رسوم توضيحية وليست مخططات هندسية.
